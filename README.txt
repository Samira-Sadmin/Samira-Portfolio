# Samira Sadmin Portfolio

A playful pastel portfolio inspired by the supplied reference: mint, blush pink, butter yellow and warm cocoa.

## Run
1. Extract the ZIP.
2. Open `samira_portfolio/index.html` in a modern browser.
3. Keep internet access available for Tailwind CSS, jQuery, Font Awesome and Google Fonts CDN resources.

## Files
- `index.html`: main HTML5 structure and portfolio content.
- `style.css`: pastel theme, responsive styling and photo positioning.
- `script.js`: jQuery interactions and contact form validation.
- `assets/profile.jpg`: supplied profile photo.
- `PRESENTATION_GUIDE.md`: presentation notes following the nine checklist sections.

HTML5 is the main document and content structure. CSS3 controls the visual design. Tailwind utility classes assist with layout, and jQuery 3.7.1 handles interactions.

The contact form validates entries in the browser but does not send email until a backend or external form service is connected.
